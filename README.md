# LLMBBC
A repository for test generation through LLM to detect breaking changes. All execution logs, prompts, and generated tests can be found here: https://zenodo.org/records/21078853.

We have packaged the tool for general purpose use at : https://github.com/CuriousBeing1508/LLMBreakGuard.git
You can run it in local or through Github Actions by forking this repository. As of now, i tried configuring it for claude. Will release it for GPT4o or the models evaluated in experiments. 

To test the tool in local, take a look at the bc-config.csv file where one sample instance is added to test.
